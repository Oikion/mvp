# Ξεκινώντας

Ακολουθήστε αυτά τα βήματα για να ρυθμίσετε τον χώρο εργασίας Oikion.

## 1. Δημιουργία Οργανισμού

Μετά την εγγραφή, θα σας ζητηθεί να δημιουργήσετε τον οργανισμό του μεσιτικού σας γραφείου. Αυτός είναι ο χώρος εργασίας όπου φυλάσσονται όλα τα δεδομένα.

## 2. Πρόσκληση Ομάδας

Μεταβείτε στις **Ρυθμίσεις > Ομάδα** για να προσκαλέσετε πράκτορες και διαχειριστές. Κάθε μέλος λαμβάνει έναν ρόλο:

| Ρόλος | Δικαιώματα |
|-------|-----------|
| **Ιδιοκτήτης** | Πλήρης πρόσβαση, χρεώσεις, διαγραφή οργανισμού |
| **Διαχειριστής** | Διαχείριση ομάδας, ρυθμίσεων, όλων των δεδομένων |
| **Πράκτορας** | Διαχείριση δικών του ακινήτων, πελατών, εντολών |
| **Παρατηρητής** | Πρόσβαση μόνο για ανάγνωση σε κοινόχρηστα δεδομένα |

## 3. Προσθήκη Πρώτου Ακινήτου

Μεταβείτε στο **MLS > Νέο Ακίνητο** και συμπληρώστε τα στοιχεία. Ο οδηγός σας καθοδηγεί βήμα-βήμα σε όλα τα πεδία.

## 4. Ρύθμιση Δημόσιου Προφίλ

Επισκεφτείτε τις **Ρυθμίσεις > Προφίλ Γραφείου** για να ρυθμίσετε τη δημόσια σελίδα σας. Ορίστε την ορατότητα σε **Δημόσιο** για να γίνει ανιχνεύσιμη.
