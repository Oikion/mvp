# Γρήγορη Εκκίνηση Γραφείου

Αυτός ο οδηγός σας καθοδηγεί στα βασικά βήματα ρύθμισης ενός νέου χώρου εργασίας Oikion.

## Ρύθμιση Οργανισμού

1. Μεταβείτε στις **Ρυθμίσεις > Οργανισμός** για να ορίσετε το όνομα, το λογότυπο και τα στοιχεία επικοινωνίας του γραφείου
2. Ορίστε την ορατότητα του **Προφίλ Γραφείου** σε **Δημόσιο** για να ενεργοποιήσετε τη δημόσια σελίδα σας
3. Ρυθμίστε την **πολιτική ιδιοκτησίας δεδομένων** στις Ρυθμίσεις > Ιδιοκτησία Δεδομένων

## Εισαγωγή Υπαρχόντων Δεδομένων

Αν έχετε υπάρχοντα δεδομένα ακινήτων και πελατών, χρησιμοποιήστε τον **Οδηγό Εισαγωγής**:

1. Μεταβείτε στο **MLS > Εισαγωγή** ή **CRM > Εισαγωγή**
2. Ανεβάστε ένα αρχείο CSV ή Excel
3. Αντιστοιχίστε τις στήλες σας με τα πεδία του Oikion
4. Ελέγξτε και επιβεβαιώστε την εισαγωγή

## Ρύθμιση Ρόλων

Αντιστοιχίστε τους κατάλληλους ρόλους στα μέλη της ομάδας σας:

| Ρόλος | Κατάλληλος Για |
|-------|---------------|
| **Ιδιοκτήτης** | Διευθύνοντας σύμβουλος / ιδιοκτήτης γραφείου |
| **Διαχειριστής** | Υπεύθυνος γραφείου, επικεφαλής ομάδας |
| **Πράκτορας** | Μεμονωμένοι πράκτορες |
| **Παρατηρητής** | Βοηθοί, ασκούμενοι |
